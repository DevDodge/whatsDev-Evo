🚀 WhatsDeveloper API

Backend Bridge API for WhatsDeveloper Manager → Evolution API

Messages
POST /api/send-message Send text message
Request Body:
{
  "phone": "201234567890",
  "message": "Hello from WhatsDeveloper!"
}
cURL Example:
curl -X POST http://localhost:3000/api/send-message \
  -H "Content-Type: application/json" \
  -d '{"phone": "201234567890", "message": "Hello!"}'
POST /api/send-image Send image with caption
Request Body:
{
  "phone": "201234567890",
  "image": "https://example.com/image.jpg",
  "caption": "Check this out!"
}
POST /api/send-video Send video with caption
Request Body:
{
  "phone": "201234567890",
  "video": "https://example.com/video.mp4",
  "caption": "Watch this!"
}
POST /api/send-audio Send audio
Request Body:
{
  "phone": "201234567890",
  "audio": "https://example.com/audio.mp3"
}
POST /api/send-document Send document
Request Body:
{
  "phone": "201234567890",
  "document": "https://example.com/document.pdf",
  "fileName": "document.pdf"
}
POST /api/send-location Send location
Request Body:
{
  "phone": "201234567890",
  "latitude": 30.0444,
  "longitude": 31.2357,
  "name": "Cairo Tower",
  "address": "Cairo, Egypt"
}
POST /api/send-contact Send contact card
Request Body:
{
  "phone": "201234567890",
  "contactPhone": "201111111111",
  "contactName": "John Doe"
}
POST /api/send-buttons Send buttons/list message
Request Body:
{
  "phone": "201234567890",
  "title": "Choose an option",
  "description": "Select one of the following",
  "buttons": ["Option 1", "Option 2", "Option 3"]
}
Instance & Chats
GET /api/instance/status Get instance connection status
cURL Example:
curl http://localhost:3000/api/instance/status
GET /api/chats Get all chats
cURL Example:
curl http://localhost:3000/api/chats
GET /api/messages/:phone Get messages for a specific chat
Parameters:
phone: Phone number (required)
limit: Number of messages (optional, default: 50)
cURL Example:
curl http://localhost:3000/api/messages/201234567890?limit=100
