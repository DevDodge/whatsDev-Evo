# ✅ Startup Scripts Updated

## Fixed Issues:

1. ✅ Removed `tee` command (not available on Windows)
2. ✅ Services now start in separate CMD windows
3. ✅ Each service has its own window that stays open
4. ✅ Increased wait time between services (8 seconds)

## How to Use:

### Start All Services:
Double-click `start-all.bat`

You will see:
- 3 separate CMD windows open
- Each running one service
- Evolution API (Port 2345)
- Backend API (Port 3456)
- Manager UI (Port 4567)

### Stop All Services:
Double-click `stop-all.bat`
OR close each CMD window manually

## URLs:

- **Evolution API:** http://localhost:2345
- **Backend API:** http://localhost:3456
- **Manager UI:** http://localhost:4567
- **Domain:** https://dk.whatsdeveloper.com/
